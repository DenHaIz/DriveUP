<h1 align="center">DriveUP</h1>

<p align="center">Драйверы и настройка Windows в одном exe.<br>Drivers and Windows tuning in one exe.</p>

## Русский

- **Обновления** — драйверы из Windows Update одной кнопкой; новее на сайтах NVIDIA, AMD, Intel, Lenovo, Asus, HP, Dell (скачиваются и ставятся прямо отсюда, с проверкой подписи производителя) и в каталоге Microsoft Update; недостающие Visual C++, .NET и DirectX 9.
- **Устройства** — все устройства, их драйверы и ошибки; драйвер для неизвестного устройства — из каталога Microsoft.
- **Установка** — перетащите папку, `.inf`, `.zip` или `.cab`.
- **Резервные копии** — сохранить драйверы и вернуть их после переустановки Windows.
- **Оптимизация** — режимы «Игры», «Работа» и «Тишина» под ваш компьютер; видно, что меняется и почему, рискованное — только с вашего согласия, любую настройку можно вернуть. Замер системы «до/после» — по желанию.

Скачайте `DriveUP.exe` в [Releases](https://github.com/DenHaIz/DriveUP-exe/releases) и запустите. Установка не нужна, нужны права администратора. С версии 1.4 программа одна: настройки и изменения прежнего `DriveUP_Pro.exe` подхватываются сами.

## English

- **Updates** — drivers from Windows Update in one click; newer ones on the NVIDIA, AMD, Intel, Lenovo, Asus, HP and Dell sites (downloaded and installed from here, with the vendor's signature checked) and in the Microsoft Update Catalog; missing Visual C++, .NET and DirectX 9.
- **Devices** — every device, its driver and its errors; a driver for an unknown device from the Microsoft catalog.
- **Install** — drop a folder, `.inf`, `.zip` or `.cab`.
- **Backups** — save drivers and bring them back after reinstalling Windows.
- **Tuning** — Games, Work and Quiet modes fitted to your computer; you see what changes and why, anything risky needs your yes, and every setting can be returned. Before/after measuring is optional.

Download `DriveUP.exe` from [Releases](https://github.com/DenHaIz/DriveUP-exe/releases) and run it. No install needed, administrator rights required. Since 1.4 there is a single edition: settings and changes made by the former `DriveUP_Pro.exe` are picked up automatically.

## Build · Сборка

`build.cmd` → `bin\DriveUP.exe` (.NET Framework 4.8, built into Windows). Developer notes: [HANDOFF.md](HANDOFF.md).
